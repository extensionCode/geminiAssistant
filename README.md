# 크랙 캐릭터챗 어시스턴트 (유저스크립트) v2

crack.wrtn.ai 캐릭터챗 화면에서 **채팅 로그 + 대화프로필 + 유저노트 + 요약메모리**를
읽어 **Gemini API / Firebase AI Logic**에게 질문하는 도우미입니다.
평소엔 작은 🔍 아이콘만 떠 있고, 누르면 질문 창이 열립니다.

> **배포 안전성:** 이 `.user.js` 파일에는 API 키가 들어있지 않습니다. 키·firebaseConfig는
> 설치한 사람의 브라우저 저장소에만 저장됩니다. 파일을 그대로 공유해도 본인 키는 따라가지
> 않으며, 받는 사람은 각자 자기 키를 설정에 입력합니다.

## 1. 설치

1. 브라우저에 **Tampermonkey** 확장을 먼저 설치.
2. 👉 **[클릭해서 설치](https://raw.githubusercontent.com/extensionCode/geminiAssistant/main/crack-wrtn-assistant.user.js)**
   — 이 링크를 열면 Tampermonkey 설치 화면이 뜹니다. (이후 새 버전은 자동 업데이트)

### 데스크톱 (크롬·엣지·파이어폭스 등)
- 위 설치 링크를 클릭하면 됩니다. (또는 `.user.js` 파일을 브라우저 창에 드래그&드롭)

### 모바일 (안드로이드)
- **파이어폭스 안드로이드 + Tampermonkey**, 또는 **Kiwi/Lemur Browser + Tampermonkey**.
- `.user.js` 파일을 열면 설치 화면이 뜹니다.

> 일반 안드로이드 크롬은 확장프로그램을 지원하지 않습니다.

## 2. API 설정

🔍 아이콘 → ⚙(설정).

### A. Gemini API (간단)
1. https://aistudio.google.com/apikey 에서 키 발급.
2. 제공자 = **Gemini API** → 키 입력 → 저장. (모델은 질문창에서 선택)

### B. Firebase AI Logic (firebaseConfig 방식)
1. 제공자 = **Firebase AI Logic** 선택.
2. **firebaseConfig 붙여넣기** 칸에 파이어베이스 콘솔의 설정 코드를 통째로 붙여넣기.
   → apiKey·projectId·appId 가 **자동 인식**됩니다. `✓ 인식됨` 표시 확인 후 **저장**.
   ```js
   const firebaseConfig = {
     apiKey: "AIza...",
     projectId: "my-project",
     appId: "1:123:web:abc",
     ...
   };
   ```
   - 백엔드는 **Vertex AI**, 리전은 **global** 로 고정됩니다 (최신 모델이 global 에만 있어서).
   - `<script type="module">` … `</script>` 블록 전체를 그대로 붙여넣어도 됩니다.
   - 모델은 질문창에서 선택.

> **참고 (Firebase AI Logic 동작 조건)**
> - 파이어베이스 콘솔에서 **Firebase AI Logic**(구 Vertex AI in Firebase)을 활성화해야 합니다.
> - **App Check**는 반드시 **"미적용(unenforced)"** 상태여야 합니다 (토큰 입력칸 없음).
> - apiKey에 **HTTP 리퍼러(도메인) 제한**이 걸려 있으면 호출이 막힙니다. 제한을 풀어두세요.

## 3. 대화프로필 / 유저노트 / 요약메모리 첨부

이 데이터들은 채팅 화면이 아니라 `crack-api.wrtn.ai` 서버에서 불러옵니다.
스크립트가 **정확한 API 엔드포인트로 직접 데이터를 가져옵니다** (세션 쿠키 사용).

| 항목 | crack-api 엔드포인트 |
|---|---|
| 유저노트 | `/crack-gen/v3/chats/{id}` → `data.story.userNote.content` |
| 대화프로필 | `/crack-api/profiles/{pid}/chat-profiles` → 룸의 `chatProfile._id` 와 일치하는 프로필 |
| 요약메모리 | `/crack-gen/v3/chats/{id}/summaries?type=longTerm` → `data.summaries[]` |

- 메인 창의 체크박스 3개로 **각 항목 전송 여부**를 켜고 끌 수 있습니다.
- 체크박스 옆 점: 🟢 `●` = 데이터 확보됨 / ⚪ `○` = 아직 못 가져옴.
- 창을 열면 자동으로 데이터를 불러옵니다. 안 잡히면 **🔄 불러오기** 버튼을 누르세요.
- 그래도 ⚪ 이면 채팅방을 새로고침한 뒤 다시 시도하세요.
- **요약메모리**는 100개가 넘어도 `nextCursor` 페이지네이션으로 전부 수집합니다.
  실제 질문에 함께 보내는 개수는 질문창의 **"요약메모리 보낼 개수"**(기본 40, 최근 N개)로 조절하세요.
  메인 창에 `요약메모리(40/112)` 처럼 [보내는 수/전체 수]가 표시됩니다.
- 수집한 요약메모리는 채팅방별로 **저장돼서 페이지를 새로고침해도 유지**됩니다.
- 패널 맨 아래에 **버전 · 제공자 · 환율**이 표시됩니다.

## 4. 사용법

1. 채팅방에서 🔍 클릭 → 창 열림.
2. 질문창에서 **채팅 로그 보낼 메시지 수**(기본 20, 메시지 단위 — 캐릭터·나 왕복 1회 = 2개)와
   **요약메모리 보낼 개수**(기본 40)를 조절.
3. 체크박스로 대화프로필/유저노트/요약메모리 첨부 여부 선택.
4. **모델·생각**은 질문창에서 바로 선택.
   - 모델: 드롭다운에서 선택. 기본 **Gemini 3.5 Flash**(2026-05 최신). 3.1 Flash-Lite, 3.1 Pro,
     구버전 2.5 Flash/Pro도 선택 가능. `-latest` 별칭은 Vertex에서 안 돼서 구체 버전만 제공하며,
     목록에 없으면 **직접 입력…** 으로 모델명을 넣으세요.
   - 생각: 모델이 답하기 전 **추론(thinking)하는 양**. `끔`이면 빠름(권장), `깊게`면 느리지만 더 숙고.
     → **2.5 Flash도 기본은 thinking이 켜져 있어** 느립니다. 느리면 `끔`으로.
5. 질문 입력 후 **물어보기** (`Ctrl+Enter`).
6. 질문/답변이 **대화 형태로 쌓입니다.** 이어서 후속 질문도 가능 (예: "더 짧게", "다른 톤으로").
7. 각 대화의 버튼:
   - **복사** — 답변을 클립보드로.
   - **수정** — 그 질문을 입력칸으로 되돌리고 해당 턴 삭제 → 고쳐서 다시 물어보기.
   - **삭제** — 그 질문/답변 턴 제거.
   - **↻ 재생성** — **맨 아래(최신) 답변에만** 표시. 같은 질문을 다시 생성.
     (예전 답변 재생성은 대화 맥락이 어긋나므로 비활성화)
8. 답변마다 **입력/출력(·추론) 토큰 수 + 추정 비용**(USD·원화)이 표시됩니다.
   - 비용은 모델 단가 기준 *추정치*입니다 (단가는 수시로 바뀜).
9. **🔍 미리보기** 버튼 — AI 에게 실제로 보내지는 전체 내용과 항목별 글자수를 확인할 수 있습니다.

### 응답이 느릴 때
- **생각 = 끔** 으로 (가장 큰 효과).
- 메인 창 `입력 ≈Nk자` 표시를 보고, 크면 **채팅 로그 보낼 메시지**와 **요약메모리 보낼 개수**를 줄이기.
- 체크박스로 당장 불필요한 첨부(대화프로필/유저노트/요약메모리)는 끄기.

- **질문 기록은 채팅방별로 저장**됩니다. 창을 닫거나 페이지를 새로고침해도,
  다른 채팅방에 갔다 돌아와도 그 방의 대화가 그대로 남아 있습니다.
- 대화가 길어졌으면 **비우기** 버튼으로 그 채팅방 기록을 초기화.
- 아이콘은 **드래그**로 위치 이동 가능 (저장됨).
- **채팅 로그는 `/messages` API로 자동 수집**됩니다 — 위로 스크롤할 필요 없이
  "보낼 개수"만큼 과거 메시지를 가져옵니다. (API 실패 시엔 화면에 로드된 만큼만 사용)
  보낼 개수에 상한은 없지만, **200개를 넘기면 전송 시 비용·시간 경고창**이 뜹니다.

## 5. 문제 해결

| 증상 | 해결 |
|---|---|
| 점이 계속 ○ (데이터 못 가져옴) | 잠시 대기 또는 🔄 불러오기. 안 되면 채팅방 새로고침. |
| 첨부 내용이 이상함 | **🔍 미리보기**로 실제 전송 내용 확인. 로딩이 덜 됐으면 잠시 후 재시도. |
| 모델 not found (Firebase) | 그 모델이 프로젝트에 없는 경우 — 모델 드롭다운에서 2.5 Flash 등으로 변경. |
| 401 / API key invalid | 키·firebaseConfig 오타 확인. |
| 403 (Firebase) | AI Logic 활성화 여부, App Check 미적용 여부, apiKey 도메인 제한 확인. |
| 응답 차단 | 안전설정은 이미 BLOCK_NONE. 모델·프롬프트 조정. |
| 응답이 느림 | 생각 = 끔. 채팅 로그·요약메모리 개수 줄이기. |
| 아이콘 안 보임 | Tampermonkey 스크립트 ON 여부, URL 이 crack.wrtn.ai 인지 확인. |

## 6. 커스터마이즈

- **시스템 프롬프트**: 설정에서 AI 역할·답변 스타일 수정.
- **채팅 로그**: `/messages` API 로 수집. 사이트 변경 시 폴백용 DOM 스크래퍼
  `scrapeChatFromDom()`(`data-message-group-id`, `items-end`, `.wrtn-markdown`) 수정.
- **데이터 추출**: `getFeatures()`(`findUserNote`/`findProfile`/`findSummary`)가
  crack-api 응답에서 유저노트·대화프로필·요약메모리를 뽑습니다.
- **원화 환율**: `open.er-api.com` 에서 자동으로 가져옵니다 (1시간 캐시, 별도 설정 불필요).
